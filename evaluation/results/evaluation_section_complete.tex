\section{Evaluation and Results}
\label{sec:evaluation}

We evaluate our LLM-guided fuzzing approach across three dimensions: 
(1) specification knowledge extraction, 
(2) test coverage and efficiency, and 
(3) comparative performance against a random baseline. 
Both fuzzers executed 15 iterations under identical conditions.

\subsection{Specification Knowledge Extraction}

The automated extraction process identified \textbf{10} 
protocol rules from ARINC~664 Part~7 and generated \textbf{96} 
violation test cases (6.9 per rule on average). 
This demonstrates the system's ability to systematically extract 
testable requirements without manual annotation (Table~\ref{tab:phase1}).

\subsection{Fuzzer Comparison}

Table~\ref{tab:fuzzer-comparison} presents comparative results. 
The LLM-guided fuzzer achieved 15.5\% higher average reward 
(0.987 vs 0.854), demonstrating more effective test case selection. 
Both achieved {}/8 VL coverage, but the LLM-guided approach explored 
4 mutation types versus 8 for the baseline.

\subsubsection{VL Testing Distribution}

Table~\ref{tab:vl-distribution} shows testing distribution. 
The LLM-guided fuzzer achieved \textbf{uniform distribution} (20\% per VL), 
while the random baseline showed significant imbalance 
(33.3\% on one VL vs 6.7\% on another), demonstrating adaptive exploration.

\subsubsection{Parameter Exploration Efficiency}

Table~\ref{tab:efficiency} demonstrates focused parameter exploration. 
The LLM selected only 4 strategic BAG values 
([3.0, 5.0, 8.0, 10.0]) rather than exhaustive enumeration, 
proving efficient boundary testing with minimal test cases.

\subsubsection{LLM Reasoning Quality}

Analysis of LLM decision-making reveals:
\begin{itemize}
\item 93.3\% edge-case strategy (boundary-focused testing)
\item Consistent reasoning patterns: identify under-tested VLs, 
select boundary values, isolate specific protocol violations
\item Example reasoning: ``Focus on sequence-number validation 
(below\_min=0, above\_max=256) while keeping BAG valid to isolate sequence handling''
\end{itemize}
