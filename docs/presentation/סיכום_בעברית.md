## 📊 מה כלול במסמכים?

### על ה-Extractor (שלב 1):

✅ **איך זה עובד:**
- PDF (ARINC 664 Part 7) → חילוץ עם LLM → JSON מובנה
- שני שלבים: Discovery + Structured Extraction
- אימות עם 3 מודלים (GPT, Claude, Gemini)

✅ **תוצאות:**
- 10 חוקי פרוטוקול
- 96 test cases
- 36 סוגי violations
- אפס עבודה ידנית

✅ **דוגמאות:**
- JSON של חוק BAG עם ערכים מותרים
- JSON של test cases עם סיבות להפרות
- צילומי מסך מומלצים

### על ה-Fuzzer עם Reasoning (שלב 2):

✅ **איך זה עובד:**
- 3 קומפוננטות בלולאה
- Component 1: מנתח תוצאות → מחשב reward
- Component 2: LLM מחליט מה לבדוק הבא
- Component 3: מייצר frames → מריץ סימולטור

✅ **Reasoning של ה-LLM:**
- דוגמאות אמיתיות מריצות
- Iteration 0: "Early exploration..."
- Iteration 5: "VL 2001 has highest reward..." (למידה!)
- Iteration 12: "Aggressive combo..." (צירוף מתקדם)

✅ **למידה:**
- מסורט מתחילת הריצה לסוף
- רואים איך ה-LLM לומד ומשתפר
- מנצל VLs מוצלחים, מגוון כשצריך

## 🎓 השקופיות שאני ממליץ (קצר)

### על ה-Extractor (5 שקופיות):

1. **סקירה:** מה הבעיה, מה הפתרון
2. **תהליך:** PDF → Extraction → JSON
3. **דוגמה - חוקים:** צילום/JSON של חוק BAG
4. **דוגמה - test cases:** צילום/JSON של 3-4 test cases
5. **אימות:** Multi-model validation (κ=0.79)

### על ה-Fuzzer (7-8 שקופיות):

1. **ארכיטקטורה:** דיאגרמה של 3 הקומפוננטות
2. **מה ה-LLM רואה:** חוקים, test cases, היסטוריה, rewards
3. **איך ה-LLM מחליט:** דוגמת JSON החלטה
4. **Reasoning - Iteration 0:** חקירה ראשונית
5. **Reasoning - Iteration 5:** למידה ("VL X has highest reward")
6. **Reasoning - Iteration 12:** צירופים מתקדמים
7. **השוואה:** LLM מול Random (טבלה)
8. **תוצאות:** מספרים מרכזיים
