\subsection{Simulator Validation}
\label{sec:simulator-validation}

Our ns-3 AFDX simulator was validated through 145 automated unit tests covering all protocol mechanisms defined in ARINC~664 Part~7. The test suite comprises three components: \textit{(i)} sending end system tests (58 tests) validating frame structure, VL parameter compliance, and redundant transmission; \textit{(ii)} switch functionality tests (46 tests) verifying filtering, BAG policing, forwarding logic, and traffic shaping; and \textit{(iii)} receiving end system tests (41 tests) confirming frame integrity, sequence management, and redundancy handling. All 145 tests passed successfully, demonstrating full compliance with the ARINC~664 Part~7 specification and establishing the simulator's fidelity as a reliable testbed for security evaluation.
